# 7. jupyter

The “notebook” environment you’ll use to run and display code + visuals together.

What it does:
Creates an interactive environment where you can combine text, code, charts, and explanations.
(Perfect for Data Analytics portfolios.)

You’ll use it to:

• Run and test Python code cell by cell

• Document your work (like a digital lab notebook)

• Present analysis results

Command to open it:

jupyter notebook
