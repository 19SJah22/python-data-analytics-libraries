# 4. seaborn

Beautiful, high-level charts built on top of matplotlib.

What it does:

Makes complex plots simple and aesthetically nice.

You’ll use it to:

• Create histograms, box plots, and heatmaps easily

• Explore relationships in data visually

• Make dashboards and reports look more professional

Example:

import seaborn as sns

sns.countplot(x="type", data=df)

plt.show()
